\section{Pre-processing}
\begin{itemize}

\section{Modeling / Methods}

The models used in this experiment were from the \texttt{scikit-learn} package: \texttt{DecisionTreeClassifier}, \texttt{RandomForestClassifier}, and \texttt{GradientBoostingClassifier}. For each classifier, I investigated the effect of class weights on model performance, given the highly imbalanced nature of the dataset. Stratified 10-fold cross-validation was then used to ensure class proportions were preserved in each fold. The primary evaluation metric was the macro-averaged F1 score, which is suitable for imbalanced classification problems. These decisions or flow for each model were as follows:

\subsection{Decision Tree Classifier}
\begin{itemize}
    \item Trained a baseline \texttt{DecisionTreeClassifier} without class weighting and evaluated its performance using cross-validation.
    \item Trained a decision tree with \texttt{class\_weight='balanced'} to address class imbalance.
    \item Compared the cross-validation F1 scores of both models which led me to consider strictly the baseline \texttt{DecisionTreeClassifier} due to little improvement in score.
    \item Performed a grid search to optimize hyperparameters (\texttt{max\_depth}, \texttt{min\_samples\_split}, \texttt{min\_samples\_leaf}) and selected the best model for further analysis.
\end{itemize}

\subsection{Random Forest Classifier}
\begin{itemize}
    \item Trained three versions of the \texttt{RandomForestClassifier}:
    \begin{itemize}
        \item Baseline (no class weighting)
        \item With \texttt{class\_weight='balanced'}
        \item With \texttt{class\_weight='balanced\_subsample'}
    \end{itemize}
    \item Compared their cross-validation F1 scores to assess the impact of class weighting.
    \item The baseline random forest performed slightly better than the weighted versions.
    \item Performed a grid search to optimize hyperparameters (\texttt{n\_estimators}, \texttt{max\_depth}, \texttt{max\_features}) and selected the best model.
\end{itemize}

\subsection{Gradient Boosting Classifier}
\begin{itemize}
    \item Trained a baseline \texttt{GradientBoostingClassifier} and evaluated its cross-validation F1 score.
    \item Performed a grid search to optimize hyperparameters (\texttt{n\_estimators}, \texttt{learning\_rate}, \texttt{max\_depth}).
    \item Selected the best model from the grid search for downstream analysis.
\end{itemize}

Therefore, I focus on the macro-averaged F1 score, which gives more weight to the minority class and provides a balance between precision and recall. \section{Conclusion}
In conclusion, the best model for this dataset is the \texttt{RandomForestClassifier} due to its robustness and strong generalization to the minority class. Notably, it achieved a high macro F1-score, favorable confusion matrix results, and a strong ROC-AUC score. Additionally, the training time was only 1.04 seconds, significantly faster than the 435 seconds required by Gradient Boosting. Based on these results, I can confidently recommend the \texttt{RandomForestClassifier} as it provides the best balance between performance, interpretability, and computational efficiency for this task. Future work could include: feature importance selection to find what key predictors contribute to the minority class and or resampling techniques.
